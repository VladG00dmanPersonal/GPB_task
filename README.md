# GPB_task

## Задача

```
Генерация фейковых финансовых новостей и их классификация.

Вам предстоит построить полный пайплайн: от поиска данных до оценки модели. Задача состоит из трёх этапов:

    Поиск данных. Найдите публичный датасет финансовых новостей или соберите его самостоятельно из открытых источников. Допускаются новости на русском или английском языке — на ваш выбор. Итоговый набор должен содержать достаточно качественных примеров для обучения модели.

    Генерация фейковых новостей. На основе реальных новостей создайте синтетический набор фейковых. Фейки должны содержать осознанно спроектированные ошибки. Примеры таких ошибок:

    Противоречие общеизвестным фактам.
    Абсурдные числовые показатели.
    Слишком громкие, многообещающие, эмоциональные, манипулятивные тексты. Ваша цель — сделать фейки похожими на правду внешне, но содержащими фактические или логические несостыковки, собрать датасет так, чтобы обучить качественную модель для выявления фейков.

    Классификация. Обучите модель машинного обучения, разделяющую реальные и фейковые новости на полученных данных. Вы можете использовать любые открытые модели и архитектуры, кроме уже обученных под такую же или подобную задачу (например, классификацию любых, нефинансовых новостей). Использование предобученных языковых моделей общего назначения разрешено. Обучите классификатор, оцените его и проанализируйте результаты, кратко опишите ваши выводы по эксперименту.
```

## Моё решение

### Датасет

#### Источник
Был взят набор данных [FinSen](https://www.kaggle.com/datasets/yogeshchary/financial-news-dataset?select=Financial_Sentiment_Categorized.csv), который произвел революцию в анализе финансовых рынков, объединив экономические и финансовые новостные статьи из 197 стран с данными о фондовом рынке. Набор данных охватывает период с 2007 по 2023 год и содержит 160 000 записей о новостях финансового рынка.

#### Генерация ложных меток
Для генерации фейковых данных была использована модель [qwen3.5:9b](https://ollama.com/library/qwen3.5:9b) через Ollama, чтобы LLM могла менять факты, числа, окрас текста сохраняя общую структуру и смысл, причём делает она это бесплатно локально. Ноутбук `notebooks/DataGen.ipynb` на основе системного промпта в `configs/qwen_system_prompt.txt` генерирует ложные статьи. Затем файл с итоговым датасетом сохраняется в `data/FinalFinancial.csv` (папка data создаётся в самом ноутбуке)

#### Итог
Для примера было взято 100 семплов реальных записей и догенерированно ещё 100 ложных записей. Всего в датасете 200 строчек с сбалансированным классом.

### Классификация

#### Модель

Так как в основном ложные статьи придерживаются определенного стиля с излишне громкими, эмоциональными, манипулятивными текстами, для первоначальной модели был выбран градиентный бустинг `CatBoostClassifier`, куда можно удобно передать текстовые фичи. `CatBoost` самостоятельно считает `TF-IDF` для переданного текста, и на основе взешанной частотности определенных слов классифицирует тексты.

В отличии от более сложных методов NLP, градиентный бустинг легко обучается и быстро инференсится даже на процессоре.

**Выбранные параметры для `CatBoostClassifier`**:
- `iterations=1000` - этого хватает, так как модель переобучается уже на первой сотне итераций
- `eval_metric='AUC'` - для валидационной части выбрана популярная метрика для бинарной классификации, которая оценивает не только итоговые классы, но и их ранжирование по уверенности модели. По этой метрике модель засекает переобучение
- `early_stopping_rounds=100` - остановка обучения, если на 100 итераций валидационная метрика не увеличилась
- `text_features=['text']` - передаём модели наш текст. CatBoost внутри сам разбивает текст на токены, чистит его, а затем преобразует в текстовые фичи на основе TF-IDF
- `random_seed=SEED` - фиксируем сид для воспроизводимости
- `use_best_model=True` - используем модель с лучшей итерации по валидационной метрике

### Итог

CatBoostClassifier хорошо себя показал (ROC AUC > 0.95), значит ложные статьи, где специально использованы громкие, многообещающие, эмоциональные, манипулятивные тексты легко классифицировать лишь по взешанному частотному анализу слов. 

### Точки роста

К сожалению, я не успел нагенерировать побольше данных, чтобы метрики были более детальными. Кроме того, возможно стоило бы изменить системный промпт для генерации ложных статей, чтобы их было более сложно классифицировать лишь по красивым словам, также можно добавить аугментаций для настоящих статей, чтобы они оставались правдивыми но меняли свой окрас. Возможно тогда бы понадобились более сложные модели по типу RNN, чтобы модель могла оценивать смысловые факты в статье, но в контексте задачи это возможно излишняя сложность.

## Запуск решения

Первым делом установите зависимоти через UV
```bash
uv sync
```

### 0. Генерация данных
**Если вы хотите пропустить этот шаг, то скачайте [отсюда](https://disk.yandex.ru/d/2kW11mJmXdqlxQ) архив и положите в корневую папку проекта.**

Запустите ноутбук `notebooks/DataGen.ipynb`, внутри него в разделе Dependencies можно настроить модель, сид, параметры генерации. В `configs/qwen_system_prompt.txt`  можно изменить системный промпт для генерации ложных статей.

Для запуска ноутбука требуется установленная ollama на пк, модель по дефолту требует ~9GB графической памяти.

### 1. Обучение модели, получение результатов
Перед запуском убедитесь, что:
1. либо в корне у вас есть архив `FinalFinancial.csv.zip`
2. либо вы сами сгенерировали данные, которые будут лежать в `data/`

Смело можно запустить весь ноутбук `notebooks/main.ipynb` на CPU, всё обучится с теми же результатми, так как сиды зафиксированы.
